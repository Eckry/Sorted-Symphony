# Sorted Symphony
This was done with the purpose of helping those students or curious people who decide to study sorting algorithms. I hope this page helps you resolve your doubts about any algorithm.

## Installation
Clone the repository and install dependecies: 
```bash
$ git clone https://github.com/Eckry/Sorted-Symphony.git
$ cd Sorted-Symphony
$ npm install
```

Start development:
```bash
$ npm run dev
```
You can see it here: [https://sorted-symphony.vercel.app/](https://sorted-symphony.vercel.app/)
